1. Choosing the Right Architecture for Your Data

Every deep learning architecture encodes a different assumption (inductive bias) about how data is structured:

  • Convolutional Neural Networks (CNNs): Best for spatial grid data such as 2D/3D images, medical scans, and spectrograms. Sliding filters detect local edges, textures, and shapes regardless of where they appear in the image.
  • Recurrent Neural Networks (RNNs): Built for sequential or time-series data (log events, sensor streams, text). They pass a hidden state from one time step to the next, though vanilla RNNs struggle to remember long sequences due to vanishing gradients.
  • Long Short-Term Memory (LSTM): An upgraded RNN using forget, input, and output gates plus a dedicated cell state to retain long-range dependencies across sequences.
  • Transformers: Replace step-by-step recurrence with Self-Attention, allowing every token or image patch to attend directly to every other element in parallel. The backbone of modern NLP, multimodal AI, and Vision Transformers (ViT).
  • Transfer Learning: Reusing weights pretrained on massive datasets (such as ImageNet or large text corpora) and fine-tuning the final layers on a smaller domain-specific dataset—typically cutting training time and improving accuracy when labeled data is scarce.

3. Convolutional Neural Networks (CNNs) for Images

A CNN progressively reduces spatial height and width via pooling or strided convolutions while increasing feature channel depth. Notice the tensor shape flow from (Batch, 3, 64, 64) down to class logits (Batch, num_classes):

import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
    def __init__(self, num_classes: int = 4) -> None:
        super().__init__()
        self.features = nn.Sequential(
            # Input: (B, 3, 64, 64) -> Output: (B, 16, 32, 32)
            nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
            nn.BatchNorm2d(16),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),

            # Input: (B, 16, 32, 32) -> Output: (B, 32, 16, 16)
            nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(kernel_size=2),

            # Global average pooling collapses (B, 32, 16, 16) -> (B, 32, 1, 1)
            nn.AdaptiveAvgPool2d((1, 1))
        )
        self.classifier = nn.Linear(32, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = self.features(x)
        x = torch.flatten(x, start_dim=1)  # (B, 32)
        return self.classifier(x)          # (B, num_classes)

# Quick shape verification
cnn = SimpleCNN(num_classes=4)
dummy_images = torch.randn(8, 3, 64, 64)
print("CNN output shape:", cnn(dummy_images).shape)  # torch.Size([8, 4])

4. Sequence Modeling: Vanilla RNN vs. LSTM

Both nn.RNN and nn.LSTM expect 3D tensors shaped (Batch, Sequence_Length, Features) when batch_first=True. Below is a side-by-side sequence classifier (e.g., classifying log sequences or time-series windows):

import torch
import torch.nn as nn

class SequenceClassifier(nn.Module):
    def __init__(self, input_dim: int, hidden_dim: int, num_classes: int, use_lstm: bool = True) -> None:
        super().__init__()
        self.use_lstm = use_lstm
        if use_lstm:
            self.rnn = nn.LSTM(
                input_size=input_dim,
                hidden_size=hidden_dim,
                num_layers=2,
                batch_first=True,
                dropout=0.2
            )
        else:
            self.rnn = nn.RNN(
                input_size=input_dim,
                hidden_size=hidden_dim,
                num_layers=2,
                nonlinearity="tanh",
                batch_first=True
            )
        self.fc = nn.Linear(hidden_dim, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if self.use_lstm:
            # LSTM returns output sequence plus final (hidden_state, cell_state)
            _, (h_n, _) = self.rnn(x)
        else:
            # Vanilla RNN returns output sequence plus final hidden_state
            _, h_n = self.rnn(x)

        # Take the final layer's hidden state: shape (Batch, hidden_dim)
        last_hidden = h_n[-1]
        return self.fc(last_hidden)

# Example: Batch of 16 sequences, each 20 time steps long, 10 features per step
seq_batch = torch.randn(16, 20, 10)
rnn_model = SequenceClassifier(input_dim=10, hidden_dim=64, num_classes=2, use_lstm=False)
lstm_model = SequenceClassifier(input_dim=10, hidden_dim=64, num_classes=2, use_lstm=True)

print("RNN output shape: ", rnn_model(seq_batch).shape)   # torch.Size([16, 2])
print("LSTM output shape:", lstm_model(seq_batch).shape)  # torch.Size([16, 2])

5. Transformers & Self-Attention from Scratch in PyTorch

Unlike RNNs, a Transformer processes all sequence tokens simultaneously using Multi-Head Self-Attention. Because attention itself has no built-in sense of token order, we add Positional Embeddings before passing tokens into nn.TransformerEncoder:

import torch
import torch.nn as nn

class TransformerTextClassifier(nn.Module):
    def __init__(
        self,
        vocab_size: int,
        d_model: int = 64,
        nhead: int = 4,
        num_layers: int = 2,
        max_len: int = 128,
        num_classes: int = 3
    ) -> None:
        super().__init__()
        self.token_emb = nn.Embedding(vocab_size, d_model)
        self.pos_emb = nn.Embedding(max_len, d_model)

        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=d_model * 4,
            dropout=0.1,
            batch_first=True
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.classifier = nn.Linear(d_model, num_classes)

    def forward(self, token_ids: torch.Tensor) -> torch.Tensor:
        batch_size, seq_len = token_ids.shape
        positions = torch.arange(seq_len, device=token_ids.device).unsqueeze(0).expand(batch_size, seq_len)

        x = self.token_emb(token_ids) + self.pos_emb(positions)
        encoded = self.encoder(x)              # (Batch, Seq_Len, d_model)
        pooled = encoded.mean(dim=1)           # Mean pool across sequence tokens
        return self.classifier(pooled)         # (Batch, num_classes)

# Example: Batch of 8 tokenized bug reports (length 32 tokens)
sample_tokens = torch.randint(0, 5000, (8, 32))
transformer_model = TransformerTextClassifier(vocab_size=5000, num_classes=3)
print("Transformer output shape:", transformer_model(sample_tokens).shape)  # torch.Size([8, 3])

6. Transfer Learning: Two-Stage Feature Extraction & Fine-Tuning

In real-world projects, training a deep CNN or Transformer from scratch on a small dataset often overfits. Instead, use Transfer Learning in two disciplined stages:

  1. Stage 1 — Feature Extraction (Freeze Backbone): Load a pretrained model (e.g., ResNet18), freeze all backbone parameters (requires_grad = False), replace the final classification head to match your target classes, and train only the new head for a few epochs.
  2. Stage 2 — Fine-Tuning (Unfreeze Top Layers with Low Learning Rate): Unfreeze the upper backbone layers and train end to end with a much smaller learning rate (such as 1e-4) so pretrained filters adapt gently without catastrophic forgetting.
import torch
import torch.nn as nn
from torchvision import models

def build_transfer_resnet(num_classes: int = 2) -> nn.Module:
    # 1. Load pretrained ImageNet weights
    weights = models.ResNet18_Weights.DEFAULT
    model = models.resnet18(weights=weights)

    # 2. Freeze all convolutional backbone layers
    for param in model.parameters():
        param.requires_grad = False

    # 3. Replace final fully connected layer (unfrozen by default)
    in_features = model.fc.in_features
    model.fc = nn.Sequential(
        nn.Dropout(0.3),
        nn.Linear(in_features, num_classes)
    )
    return model

# Stage 1 Optimizer: updates ONLY model.fc parameters
transfer_model = build_transfer_resnet(num_classes=2)
optimizer_stage1 = torch.optim.Adam(transfer_model.fc.parameters(), lr=1e-3)

# Stage 2 (Optional Fine-Tuning): unfreeze last residual block (layer4) with smaller LR
for param in transfer_model.layer4.parameters():
    param.requires_grad = True

optimizer_stage2 = torch.optim.Adam([
    {"params": transfer_model.layer4.parameters(), "lr": 1e-4},
    {"params": transfer_model.fc.parameters(),     "lr": 5e-4}
])

print("Trainable parameters:", sum(p.numel() for p in transfer_model.parameters() if p.requires_grad))

7. Practical Training Checklist for Deep Learning Beginners

  • Sanity-Check on One Batch First: Before training on thousands of samples, verify your model can drive training loss near zero on a single mini-batch of 8–16 samples.
  • Match Loss Functions to Output Activations: Use nn.CrossEntropyLoss() on raw multi-class logits (do not apply Softmax inside forward()), and nn.BCEWithLogitsLoss() for binary/multi-label logits.
  • Switch Modes Properly: Always call model.train() before training epochs and model.eval() with torch.no_grad() during validation so Dropout and BatchNorm behave deterministically.
  • Clip Gradients in RNNs/LSTMs: Add torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0) before optimizer.step() to prevent exploding gradients on long sequences.
