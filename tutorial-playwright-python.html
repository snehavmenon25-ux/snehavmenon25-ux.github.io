1. Why Playwright for Modern UI & API Testing?

Traditional browser automation often fails intermittently because scripts click buttons before JavaScript finishes rendering them. Playwright solves this at the protocol level:

  • Auto-Waiting: Before clicking or typing, Playwright automatically verifies the element is attached to the DOM, visible, stable, and enabled.
  • Isolated Browser Contexts: Every test gets a clean incognito-like session in milliseconds without launching a new browser process.
  • Built-in Network Control: You can mock API failures, inspect network headers, and combine REST API setup with UI checks in one script.

2. Environment Setup (Step-by-Step)

Open your terminal (Command Prompt, PowerShell, or macOS/Linux Terminal) and run these commands one by one:

# 1. Create a clean project folder and enter it
mkdir playwright-python-starter
cd playwright-python-starter

# 2. Create and activate a Python virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. Install PyTest, the official Playwright plugin, and HTML reporting
pip install pytest pytest-playwright pytest-html

# 4. Download Chromium, Firefox, and WebKit browser binaries
playwright install

3. Recommended Folder Structure

Even in a beginner project, separating element locators from test assertions prevents maintenance headaches later. Create this layout:

playwright-python-starter/
├── pages/
│   └── todo_page.py        # Locators and page actions (Page Object)
├── tests/
│   └── test_todo_app.py    # Test scenarios and assertions
└── pytest.ini              # Default PyTest configuration

4. Step-by-Step Implementation

Step A: Configure PyTest Defaults (pytest.ini)

File: pytest.ini

This tells PyTest where your tests live and sets Chromium as the default browser.

[pytest]
testpaths = tests
addopts = --browser chromium --headed -v

Step B: Build the Page Object (pages/todo_page.py)

File: pages/todo_page.py

Notice that we use user-facing locators (get_by_placeholder, get_by_role) instead of fragile CSS paths, and we keep assertions out of this file.

from playwright.sync_api import Page, Locator

class TodoPage:
    URL = "https://demo.playwright.dev/todomvc/#/"

    def __init__(self, page: Page) -> None:
        self.page = page
        self.new_todo_input: Locator = page.get_by_placeholder("What needs to be done?")
        self.todo_items: Locator = page.get_by_test_id("todo-item")

    def open(self) -> None:
        self.page.goto(self.URL)

    def add_task(self, task_text: str) -> None:
        self.new_todo_input.fill(task_text)
        self.new_todo_input.press("Enter")

    def toggle_task(self, index: int) -> None:
        self.todo_items.nth(index).get_by_role("checkbox").check()

    def filter_by(self, status: str) -> None:
        # status can be "All", "Active", or "Completed"
        self.page.get_by_role("link", name=status).click()

Step C: Write the End-to-End Tests (tests/test_todo_app.py)

File: tests/test_todo_app.py

Playwright provides expect(...) assertions that automatically retry until the condition passes or times out—eliminating manual time.sleep() calls.

from playwright.sync_api import Page, expect
from pages.todo_page import TodoPage

def test_add_and_complete_tasks(page: Page) -> None:
    todo = TodoPage(page)
    todo.open()

    # 1. Add two tasks
    todo.add_task("Write Playwright Page Object")
    todo.add_task("Configure CI pipeline")
    expect(todo.todo_items).to_have_count(2)

    # 2. Mark the first task as completed
    todo.toggle_task(0)
    expect(todo.todo_items.nth(0)).to_have_class("completed")

    # 3. Filter by Active tasks and verify only 1 remains visible
    todo.filter_by("Active")
    expect(todo.todo_items).to_have_count(1)
    expect(todo.todo_items.first).to_have_text("Configure CI pipeline")

def test_network_route_interception(page: Page) -> None:
    # Example: Block image requests to speed up test execution
    page.route("**/*.{png,jpg,jpeg}", lambda route: route.abort())
    todo = TodoPage(page)
    todo.open()
    expect(todo.new_todo_input).to_be_visible()

5. Running Tests & Debugging Failures

# Run tests headless (fast mode for CI/CD) and generate an HTML report
pytest --headed=false --html=report.html --self-contained-html

# Record full DOM snapshots, network logs, and screenshots on failure
pytest --tracing=retain-on-failure

# Open a saved trace file visually
playwright show-trace test-results/your-test-folder/trace.zip

6. Common Beginner Mistakes to Avoid

  • Using time.sleep(5): Always use web-first assertions like expect(locator).to_be_visible() so tests finish as soon as the UI is ready.
  • Chaining brittle XPaths: Prefer get_by_role(), get_by_label(), or get_by_test_id() so layout tweaks do not break your suite.
  • Sharing state across tests: Let PyTest's built-in page fixture give every test function a fresh browser context automatically.
