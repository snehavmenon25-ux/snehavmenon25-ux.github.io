AI Testing • PyTest & PyTorch

Writing Automated Behavioural & Drift Tests for ML Models

Testing Neural Networks Beyond Accuracy

Write deterministic PyTest checks for output probability bounds, subgroup slices, and batch inference latency thresholds.

def test_model_output_shape_and_bounds(trained_model):
    sample = torch.randn(4, 3, 224, 224)
    probs = torch.softmax(trained_model(sample), dim=1)
    assert probs.shape == (4, 2)
    assert torch.allclose(probs.sum(dim=1), torch.ones(4), atol=1e-5)
