Software Testing • Playwright

Structuring Maintainable Page Objects with SOLID Principles

Guide • UI & API Automation Architecture

How to separate locators, business workflows, and test assertions so UI changes do not break dozens of regression tests.

  1. Keep page classes focused strictly on element interactions—avoid placing assertions inside Page Objects.
  2. Inject API helpers for test data setup instead of clicking through slow UI preconditions.
  3. Run suites in parallel inside CI/CD pipelines with trace-on-failure enabled.
// C# Playwright Page Object Pattern
public class LoginPage(IPage page) {
    private ILocator EmailInput => page.GetByLabel("Email");
    private ILocator SubmitBtn  => page.GetByRole(AriaRole.Button, new() { Name = "Sign in" });

    public async Task LoginAsync(string email) {
        await EmailInput.FillAsync(email);
        await SubmitBtn.ClickAsync();
    }
}

AI Testing • PyTest & PyTorch

Writing Automated Behavioural & Drift Tests for ML Models

Guide • Testing Beyond Accuracy

Why high aggregate validation accuracy can still hide critical failures—and how to write deterministic PyTest checks for neural networks.

  1. Invariance Tests: Verify predictions remain stable under minor noise or lighting shifts.
  2. Slice Evaluation: Measure precision/recall across underrepresented data subgroups.
  3. Inference Latency Gate: Fail the build if batch inference exceeds production SLA thresholds.
import torch, pytest

def test_model_output_shape_and_bounds(trained_model):
    sample = torch.randn(4, 3, 224, 224)
    probs = torch.softmax(trained_model(sample), dim=1)
    assert probs.shape == (4, 2)
    assert torch.allclose(probs.sum(dim=1), torch.ones(4), atol=1e-5)
Responsible AI • Robustness

Evaluating Adversarial Robustness & Explainability

Guide • Trustworthy Deep Learning

A checklist for stress-testing deep learning classifiers and segmentation models against perturbations and spurious correlations.

  1. Generate small-epsilon FGSM/PGD perturbations to measure worst-case confidence drops.
  2. Use saliency or Grad-CAM overlays to confirm the model focuses on relevant regions rather than background artifacts.
  3. Log all robustness metrics per run in MLflow for reproducible model governance.
# Log robustness metrics in MLflow
import mlflow

with mlflow.start_run():
    mlflow.log_metric("clean_dice_score", 0.91)
    mlflow.log_metric("perturbed_dice_score", 0.84)
